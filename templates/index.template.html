Import & Manage Data

Import Mail from Gmail (Oauth2 Authentication)

—

Sign in with Google (OAuth) and import Gmail into this archive. Messages are tagged by source so Clear Data only removes mail imported via Gmail, not other email sources.

Imort Mail from an IMAP server (Basic Authentication)

—

Import from any IMAP mailbox using server credentials and folder selection. Counts include non-Gmail IMAP and legacy email rows. Clear Data removes IMAP and legacy imports as described in the button tooltip.

Import Messages from a WhatsApp Archive

—

Import a WhatsApp export. Chats and media are parsed into the archive. Use Clear Data to remove only WhatsApp-imported content.

Import Messages from an Instagram Archive

—

Import a Meta Instagram data export. Posts and related metadata are imported. Clear Data removes Instagram-imported material.

Import an iMessage & SMS Archive

—

Import an Apple iMessage/SMS export. Message threads are merged into the archive. Entry counts combine iMessage, SMS, and MMS where applicable.

Import a Facebook Archive (messages, albums, posts, and places)

—

Import a Facebook data export. Messenger, albums, posts, and places are imported.

Import and Manage Reference Documents

—

Open the reference documents manager to add PDFs, Word files, text, CSV, or JSON for AI context. Entries counts stored reference docs. Last run reflects linked-file import activity where applicable.

Import Linked Images to Database

—

Copy linked (referenced-on-disk) images into the database blobs so they travel with the archive. Entries shows reference-linked images. Runs as a background job.

Export Images to Filesystem

—

Write images from the database to a folder you choose on disk (local deployment). Entries is the total image count eligible for export.

Remove images stored in the database

—

Remove images that have been imported into the database. This function only offers Clear Data to remove filesystem-sourced library images; counts reflect embedded images for this archive.

Reprocess Contacts Data

—

Rebuild the contacts store from existing messages and related sources. Useful after large imports or if you have updated your contacts classification, emails matches or email exclusions

Thumbnails Creation & Location Extraction

—

Generate thumbnails and read GPS/metadata from images. May run as an interactive prompt flow or async jobs. Last run merges thumbnail and async thumbnail timestamps when both exist.

Optimise Message and Conversation for Searching

—

Turns your messages and conversations into a format the app can search through quickly.

Optimise Facebook Post Text for Searching

—

Embed Facebook post text for semantic similarity search. You can reprocess all posts or only fill missing vectors.

Optimise Facebook Album Descriptions for Searching

—

Embed Facebook album descriptions for semantic similarity search. You can reprocess all albums or only fill missing vectors.

Use AI to Classify Image Contents

—

Use local AI (e.g. Gemma via Ollama) to tag images with the contents of the image for ones that are not yet classified

Optimise the Tags on Images for Searching

—

Embed image tags for similarity search. You can reprocess all embeddings or skip unchanged tags when prompted.

Hover an option for a description, entry counts, and last run.
